# 肥鱼 · 模型养成计划

用 Godot 4.7 写的训练养成游戏：48 周，把「肥鱼」从零练成一个能开发布会的模型，
在第 48 周的发布会上把热度冲上 **50 万**。

## 剧本原型

故事底子取自 2022–2023 年那段「闭源巨头把持榜单、开源模型从下面顶上来」的历史。
排行榜上的 **蓝鲸-4o 就是 ChatGPT** —— 全场最强、最贵、也最不肯公开的那一个，
是「打破垄断」这一局里必须翻过的那座山。虎鲸-Opus 则是另一家闭源旗舰。
而「肥鱼」的设定本身就带着反差：她只有十份融资里的一份能动用（1:10），
算力靠一单位一单位地买，token 得靠数据清洗一点点攒。

## 玩法

一回合 = 一周，共 48 周。

**五项能力**：语言理解 / 推理能力 / 代码能力 / 长文本记忆 / 安全性。开局全是 5。
「综合分」= 五项平均，它决定发布会上哪些媒体愿意到场。

**一回合可以安排多项训练**，只要①算力占用之和 ≤ 算力上限，②token 够。排好后点「开始本周训练」。

### token（三档，训练效果倍率不同）

| 档位 | 图标 | 来源 | 价格 | 效果倍率 |
|---|---|---|---|---|
| III 级 通用网页 | 铜币（刻着 t） | 每周自动到账 10 单位（免费） | 0 | ×1 |
| II 级 代码 | 银币 | 采购 | 4 货币 / 单位 | ×2 |
| I 级 精选高质量 | 泛光金币 | 采购 | 16 货币 / 单位 | ×4 |

单档库存上限 60，超出的当周作废。

**采购可以撤回**：点「撤回」退掉上一笔并全额退款。但已经排进本周计划、被占用的那部分撤不动 ——
得先把它从计划里拿掉，才能退（`GameState.can_undo_purchase()` 会给出具体原因）。
跨周不能退：每周结算时采购记录清空。

### 算力

算力**不消耗**，它只是"这周能排多少训练"的容量。8 货币 = +1 单位，永久有效。开局 2。

### 四种训练

| 训练 | token | 算力 | 效果 |
|---|---|---|---|
| 预训练 | 10 | 2 | 五项各 +10（×倍率） |
| SFT 微调 | 4 | 1 | 指定能力 +8（×倍率） |
| RL 推理训练 | 2 | 5 | 指定能力 +15（×倍率） |
| 数据清洗 | 8 | 2 | 产出 4 单位高一级 token（8 个 III 级 → 4 个 II 级） |

### 月刊（第 4、8、…、44 周，共 11 期）

每期有主题和权重（代码专项、长文本挑战、安全红队……），按当期权重重算一次分，
和 7 个对手模型排榜。

- **名次奖金**：榜首 90 / 前三 50 / 上半 25 / 下半 8 货币
- **得分分成**：评测得分 × 0.04
- 两者相加就是可用资金；**融资 = 可用资金 × 10**（「肥鱼」固定融资比 1:10 —— 十份融资里只有一份能动用）
- **媒体关注度** += 评测得分 × 15 × 名次系数（榜首 2.0 / 前三 1.45 / 上半 1.0 / 下半 0.5），逐期累积

### 发布会（第 48 周）

```
最终热度 = 规模基础热度 × Π(已获得加分项) + 累计关注度
```

| 规模 | 费用 | 基础热度 | 媒体到场门槛（综合分） |
|---|---|---|---|
| GitHub 发布 | 0 | 1 万 | 0 |
| 技术报告 | 3 | 5 万 | 150 |
| 线上发布会 | 8 | 10 万 | 350 |
| 线下发布会 | 16 | 20 万 | 700 |
| 全球发布会 | 32 | 40 万 | 900 |

**加分项**（同时生效时相乘）：

- 开源项目 ×1.75 —— 「肥鱼」本剧本固定获得
- 成本最低 ×1.60 —— 固定获得（融资比 1:10，全行业研发成本最低）
- 安全度最高 ×1.30 —— 发布会当周安全性 ≥ 全场最高（对手里最猛的是蓝鲸-4o，第 48 周约 983）

**结局评级**：≥100 万 SSS（时代封面）/ ≥50 万 SS（达标通关）/ ≥30 万 S / ≥15 万 A / ≥5 万 B / 其余 C。

## 她在看着你：立绘情绪系统

左侧立绘不是一张静态图。底层是那张蓝发鲸鱼女仆的大立绘（缓慢呼吸浮动），
右下角叠一张 Q 版贴纸（浮动 + 轻微摇摆），贴纸随局面换表情：

| 触发条件 | 贴纸 | 左上角标签 |
|---|---|---|
| 综合分 < 100（还没练起来） | `sleep` 打盹 | 还在打盹 |
| 平时（有分数但没事件） | `calm` 平常 | 平常 |
| 月刊名次创新高 | `shock` 惊讶 | 创新高 |
| 拿到第 1 名 | `cheer` 欢呼 | 榜首！ |
| 名次原地不动 | `blank` 无语 | 原地踏步 |
| 名次退步 | `sad` 委屈 | 退步了 |
| 热度 ≥ 30 万但没到 50 万 | `cry` 哭 | 没达标 |
| 热度 < 30 万（惨败） | `wail` 大哭 | 惨败 |
| 发布会达成 50 万 | `love` 星星眼 | 成功啦 |

素材由 `scripts/tools/BakeChibi.gd` 从用户给的 9 张 Q 版贴纸烘焙而来（裁水印 → 取方图 → 512×512 →
从四边泛洪抠掉与边缘连通的近白背景，**用泛洪而不是全图颜色阈值，才能保住围裙和蕾丝这些同样白的地方**），
输出到 `assets/art/chibi/*.png`。心情映射写在 `scripts/data/Portraits.gd`。

配套的视觉化符号：

- **48 格赛程条**（顶栏）——一格一周，金色小格是月刊评测周，粉色格是第 48 周发布会，走过的格子会点亮；
- **热度仪表**（发布会页 / 结局页）——底槽按结局档位分成 C / B / A / S / SS / SSS 六段，中间是当前热度填充，
  金色竖线是 50 万目标线，刻度标 5 / 15 / 30 / 50 / 100 万；
- **名次折线**（月刊弹窗）——纵轴倒置（第 1 名在最上），一眼看出这几个月是在爬还是在掉，
  榜首点标金色，标题栏同时给出「▲ 名次上升 3 → 2 / ▼ 名次下滑 / — 名次持平」；
- **开训确认框**——点「开始本周训练」先弹出确认，摊开这一周的训练项、算力占用、token 消耗和训练前属性，
  给两个按钮：**重新安排**（关掉弹窗，计划原样保留，接着改）和 **确认，开始训练**。
  想空过一周就等计划清空后再点，按钮会变成「空过本周」。

### 图标（全部是代码画的）

`scripts/ui/Icon.gd` 是一个纯 `_draw()` 的图标控件，没有外部图片：颜色和尺寸随时能改，
任何分辨率都清晰。图标按"内接正方形"绘制，所以放进会把控件拉高的容器里也不会变形。

| 用途 | 画的是什么 |
|---|---|
| 资金 | 钞票（方框 + 中间圆章 + 四角花纹） |
| 算力 | CPU 芯片（方体 + 内核 + 四边引脚） |
| 媒体关注度 | 火花（四角星 + 两颗小火星） |
| 语言理解 | 纸和笔 |
| 推理能力 | 放大镜 |
| 代码能力 | 终端窗口里的 ASCII（`>` 提示符 + 光标块 + 点阵） |
| 长文本记忆 | 同心圆环（带一圈刻度） |
| 安全性 | 盾牌 + 对勾 |
| token III / II / I | 铜币 / 银币 / 泛光金币，币面刻一个小写 `t` |
| 撤回采购 | 弯箭头 |

用在哪里：顶栏的资金 / 算力 / 三档 token / 关注度，左栏五行能力的行首，
"目标能力" 的五个按钮，"采购" 的六张卡片，以及计划面板的 token 消耗行。

## 经济曲线的设计意图

平衡的核心矛盾：**算力是硬瓶颈，token 是软瓶颈，而钱只能从月刊名次来。**
每周免费到账 10 单位 III 级 token，正好够一次预训练（10 token / 2 算力），
所以"什么都不买"的躺平玩家 48 周稳定停在综合分 485 —— 够得着线上发布会（门槛 350），
但离线下发布会的门槛 700 差得很远，最好成绩只有 S 级（不算通关）。

想通关就必须把月刊奖金换成 II 级 token 和算力，把每周的训练量从"1 次预训练"顶上去。

`scripts/tests/BalanceSim.gd` 跑 12 套打法的实测结果：

| 打法 | 综合分 | 发布会 | 最终热度 | 评级 |
|---|---|---|---|---|
| A 被动：什么都不买 | 485 | 线上 | 314,150 | S（失败） |
| I 只扩算力，不买 token | 485 | 线上 | 314,150 | S（失败） |
| D 清洗流（前 30 周清洗） | 321 | 技术报告 | 149,202 | B |
| K 满配：算力 24 + I 级 token | 641 | 线上 | 341,329 | S |
| J 精选流：买 I 级 token 打 RL | 713 | 线下 | 637,410 | SS |
| C 激进：算力 12，钱全砸 II 级 token | 740 | 线下 | 638,714 | SS |
| A2 攒钱晚花 | 747 | 线下 | 636,513 | SS |
| E 均衡：算力 8 + SFT 补短板 | 760 | 线下 | 642,941 | SS |
| B 稳健：算力 6 + SFT 补短板 | 763 | 线下 | 643,134 | SS |
| F 精算：RL 打最低属性 | 929 | 全球 | 1,247,362 | SSS |
| H 抠门：算力只到 4，余钱全买 II 级 token | 1011 | 线下 | 877,983 | SS |

躺着不动必败，稳健打法是 SS，抠着算力花、用 RL 专打短板才能摸到 SSS。

## 实战演练：我自己打的那一把

`scripts/core/Playbook.gd` 是一套写成代码的打法，`--play` 和
`scripts/tests/Playthrough.gd` 共用它，所以「无头扫描」和「界面上真打」是同一套决策。

### 打法

1. 奖金一到账先补算力（唯一能花钱换永久周产能的东西），目标 17；
2. 每周免费的 10 单位 III 级 token 先吃掉一次预训练（0 货币换 +50 总属性，只吃 2 算力）；
3. 剩下的算力全跑 **II 级 RL**，因为按钱算它最划算：

   | 训练（全用 II 级 token） | 花费 | 收益 | 点属性 / 货币 |
   |---|---|---|---|
   | RL 推理训练 | 2 token = 8 货币 | 指定 +30 | **3.75** |
   | 预训练 | 10 token = 40 货币 | 全项 +100 | 2.50 |
   | SFT 微调 | 4 token = 16 货币 | 指定 +16 | 1.00 |

4. RL 永远打**当前最低**的那一项：补短板才能抬高综合分（发布会门槛看五项平均），
   均衡成长让安全性自然顶到全场最高，白拿「安全度最高 ×1.30」；
5. 第 45 周起才攒钱，攒够全球发布会的 32 货币 —— 早攒等于把钱从 token 里抽走。

### 结果

```
规模：全球发布会（32 货币 / 基础热度 400,000）
加分项：开源项目 ×1.75、成本最低 ×1.60、安全度最高 ×1.30
综合分 1049 · 总属性 5245
最终热度 1,590,854（目标 500,000）
评级：SSS · 时代封面
累计融资 9,790 · 累计支出 996 货币 · 消耗 token 668 · 最终算力 17
```

月刊名次：`3 3 3 3 2 1 1 1 1 1 1` —— 前 20 周被蓝鲸-4o 压着打，
第 24 周靠「多语言评测」这个偏语言的题目第一次翻过去，之后一路榜首。
这就是这个剧本想讲的那件事：**不是堆钱堆赢的，是把每一份融资都换成了产能。**

### 9 套配置扫描（`Playthrough.gd`）

| 配置 | 综合分 | 名次和 | 最终热度 | 档位 | 余额 | 评级 | 通关 |
|---|---|---|---|---|---|---|---|
| ① 库存上限 12 / 算力 14 / 41 周起攒 | 771 | 28 | 643,504 | 线下 | 16 | SS | ✔ |
| ② 库存 40 / 算力 14 / 41 周起攒 | 963 | 18 | 1,244,750 | 全球 | 3 | SSS | ✔ |
| ③ 库存 40 / 算力 14 / 45 周起攒 | 989 | **17** | 1,588,636 | 全球 | 0 | SSS | ✔ |
| ④ 库存 40 / 算力 12 / 45 周起攒 | 941 | 17 | 1,248,948 | 全球 | 171 | SSS | ✔ |
| ⑤ 库存 40 / 算力 17 / 45 周起攒 | **1049** | 20 | **1,590,854** | 全球 | 3 | SSS | ✔ |
| ⑥ 库存 40 / 算力 20 / 45 周起攒 | 807 | 28 | 644,279 | 线下 | 18 | SS | ✔ |
| ⑦ 新手：只买 I 级精选 / 算力 6 | 536 | 37 | 332,156 | 线上 | 28 | S | ✘ |
| ⑧ 新手：不扩算力 / 不买 token | 485 | 44 | 314,150 | 线上 | **444** | S | ✘ |
| ⑨ 只扩算力 / 不买 token | 485 | 44 | 314,150 | 线上 | 324 | S | ✘ |

三条从表里读出来的结论，也是给玩家的三条忠告：

- **别囤钱。** ⑧/⑨ 两套打法最后账上躺着 444 / 324 货币，钱没变成属性，等于白拿。
  收入是每 4 周一笔的，token 库存上限要一次吃得下整笔奖金（① 就是被库存上限 12 卡住了，
  钱烂在账上，771 分就封顶）。
- **算力买多了也是亏。** ⑥ 把算力堆到 20，钱被算力吃掉，token 买不起，反而掉回 807。
  产能要和料钱匹配。
- **I 级精选是陷阱。** ⑦ 花 16 货币/单位买 I 级，每货币只换 1.875 点属性，
  被 II 级 RL 的 3.75 点甩开一倍，最后 536 分连线下都够不着。
